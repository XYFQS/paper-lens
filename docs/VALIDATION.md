# 验证记录

2026-09-09，Windows，Zotero 9.0.6（64 位）。

## 自动化验证

- `node --test tests/*.test.cjs`：8 项通过，覆盖中英搜索、AND/OR、否定条件、模型输出校验、空关键词、元数据处理和 API 地址。
- `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-native.ps1`：40 项通过，使用独立 Zotero 配置与独立测试数据库、6 篇合成条目及父子分类。
- 新增检查覆盖文库与阅读器导航按钮、显示/隐藏切换、可折叠搜索、标题与自定义图标、成对条件按钮，以及 API 保存锁定、固定掩码、编辑与取消修改、留空保留密钥。
- 在 280、380、600 像素侧栏宽度下验证条件按钮同排等宽等高，侧栏无横向溢出。
- 实机验证了指定分类/子分类索引、磁盘缓存、双语生成、错误输出纠正、标签保存切换与人工标签保留、原生主列表结果及零结果、元数据变更失效、缺失关键词继续生成、自动更新与网络请求取消。
- 测试确认 6 篇条目与原来的 2 个文献分类均保留。
- Windows PowerShell 5.1 可生成 XPI 和完整源码 ZIP，无 npm 依赖。

## 验证边界

AI 测试使用本机模拟的 OpenAI 兼容 HTTP 服务与合成密钥，未使用真实 API Key，也未评估真实模型的关键词准确率。安装后保存自己的 API 配置并测试连接。侧栏挂载和主列表结果已由 Zotero 内部测试验证；不同屏幕缩放下的外观尚未人工检查。

测试数据与报告保存在项目 `.test` 中，不进入发行包。测试脚本不会使用个人文库，运行后保留独立测试窗口供检查，可手动关闭。`scripts/test-native.ps1` 的 `-ZoteroPath` 参数可指定其他安装路径。

## 发布前设置

修改 `addon/manifest.json` 中作者和更新地址，部署 Zotero 所需更新清单；当前占位地址不提供自动更新。测试脚本与源码使用 MIT 许可，不含 Zotero 源码或个人缓存、密钥。
