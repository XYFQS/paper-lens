### 2.0.0 / 2.0.1 新增检查

- 索引为 v2 结构：`analysis`、`workflow`、`manual` 分开存放；磁盘上不含 `searchText`，也不再有 v1 的 `labels` 字段。
- 六类关键词成对存储，模型返回未知键时会被要求纠正；重复项不会被静默合并，而是退回一轮纠正。
- 发送给模型的内容只用白名单字段：测试读取模拟服务实际收到的请求体，确认没有附件、笔记正文、分类、`dateModified`、`version` 或本地路径；会议论文的 `proceedingsTitle` 与书籍章节的 `bookTitle` 会作为期刊参与记忆句和检索。
- AI 从不写入 `workflow`、`manual` 或阅读进度：生成后这些字段仍为默认值。
- 人工校正：停用某个 AI 关键词后它不再生效、AI 的原始结果保持不变、自动记忆句随之更新；手动添加的关键词生效，并在完整重新生成后保留；恢复原始画像会回到 AI 结果。
- 记忆句：自动生成、手动改写、改写后可被搜索、清空后恢复自动版本。
- 十二个检索维度逐一验证：主题、区域、对象、方法、数据、变量、年份、期刊、阅读进度、重要程度、用途，以及条目类型与关键词的组合检索。
- 原生标签矩阵：六类前缀齐全、无中文标签名（按码点判断）、写入为自动标签、v1 旧标签被替换而人工标签保留、用户已有的同名标签被沿用而不被占用、无遗留过期标签名。
- 文献身份证（信息卡片）：跟随主列表选择、显示选中论文、过期与旧版关键词提示；身份行只在有值时显示，徽标只在阅读状态或重要程度非默认时出现；六类维度与文献管理字段各只标注一次（纯中文）；无解释性说明文字与占位填充；空维度显示为 `—`；**未点「编辑」时整个卡片只有一个控件**，没有输入框、没有关键词表单、标签也没有删除按钮。
- 文献身份证（编辑模式）：点「编辑」展开记忆句输入框、两个下拉框与用途标签，但关键词表单保持折叠；标签这时才出现 `×`；点「完成」收起并保存记忆句；「恢复自动生成」清除改写；「恢复 AI 原始画像」在有人工改动时才出现，点一次清空全部改动并重新隐藏；六个类别共用同一套关键词表单，空输入与半对输入被拒绝；后台刷新不会覆盖正在输入的记忆句。
- 下拉框与用途标签在保存后保持所选值（回归 2.0.0 修复的回退问题）。
- 文献身份证在 280、380、600 像素下均不出现横向滚动——卡片与编辑控件各验一遍。
- 主列表单选切换：单击另一篇论文后文献身份证立即跟随（不打开阅读器、不手动刷新），切回上一篇同样跟随；重复建立选择监听不会叠加第二个监听器；从阅读器标签页返回文库时重新读取文库当前选择。
- 主要结论排版：中英文两行都落在正文列（`grid-column: 2`），英文宽度明显大于序号列，且 280、380、600 像素下都不出现横向溢出。
- 面板独立性：折叠原生 item pane 或阅读器 context pane 时插件面板保持显示；插件导航按钮只隐藏/恢复自己，绝不动原生面板。
- 页面结构：恰为找文献 / 文库 / 设置三个页面，文献身份证位于搜索页内，不是第四个页面。
- 迁移在真实文件上进行：备份先于写入、加载本身不改写 v1 文件、升级后保存为 v2、损坏索引只抛出错误并保留原文件、内存索引不被空库替换。
- 重新挂载：卸载窗口会移除侧栏与观察者，再次挂载能重新建立并回到搜索页。

## 验证边界

AI 测试使用本机模拟的 OpenAI 兼容 HTTP 服务与合成密钥，未使用真实 API Key，也未评估真实模型的关键词准确率。安装后保存自己的 API 配置并测试连接。侧栏挂载和主列表结果已由 Zotero 内部测试验证；不同屏幕缩放下的外观尚未人工检查。

界面断言基于 Zotero 9.0.6 的文档对象与几何计算，不覆盖真实鼠标操作与输入法。

测试数据与报告保存在项目 `.test` 中，不进入发行包。测试脚本不会使用个人文库，只用 `.test` 下本次运行自己的临时配置目录；运行结束（成功或超时）都会按该配置路径结束对应的 Zotero 进程，不会留下占用配置目录的实例，也不会匹配到你自己正在使用的 Zotero。上述 185 项结果即由该脚本取得。`scripts/test-native.ps1` 的 `-ZoteroPath` 参数可指定其他安装路径。
