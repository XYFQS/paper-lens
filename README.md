# 文献透镜 · Paper Lens

让 Zotero 文库更容易查找。文献透镜读取文献的标题、摘要、作者、标签等条目信息，通过 AI 提取中英双语研究关键词，帮助你按研究区域、研究对象和研究方法找到相关论文。

[下载安装包](https://github.com/XYFQS/paper-lens/releases) · [反馈问题](https://github.com/XYFQS/paper-lens/issues)

## 能做什么

- **搜索文献信息**：在本地搜索标题、摘要、作者及其他已读取的条目信息，无需调用 AI。
- **生成研究关键词**：为每篇文献提取研究区域、研究对象、研究方法三类关键词，每类最多 5 个，中文和英文同时生成。
- **组合条件检索**：结合条目类型和研究关键词筛选，结果直接显示在 Zotero 主列表。
- **选择标签保存方式**：关键词可仅保存在插件中，也可同步为 Zotero 原生双语标签。

插件不读取 PDF 全文，不移动文献，不创建或删除文献分类。

## 下载与安装

当前版本为 **1.0.0**，已在 **Windows、Zotero 9.0.6（64 位）** 上测试。目前支持个人文库，暂不支持群组文库。

1. 打开 [Releases 下载页面](https://github.com/XYFQS/paper-lens/releases)，在所需版本的 **Assets** 中下载以 `.xpi` 结尾的文件。
2. 在 Zotero 中打开 **工具 → 插件**，点击齿轮菜单，选择 **从文件安装插件**。
3. 选择下载的 `.xpi` 文件，按提示完成安装；如提示重启，请重启 Zotero。
4. 点击右侧原生侧栏中的文献透镜图标，即可显示或隐藏插件；也可通过工具菜单打开。

**`.xpi` 就是安装包，不需要解压。** `Source code` 和 `-source.zip` 是源码，普通用户无需下载，也无需安装 Node.js 或其他开发环境。

## 第一次使用

### 1. 读取文献信息

在插件顶部选择 **整个个人文库** 或一个指定分类。需要同时读取其子分类时，勾选 **包含子分类**，默认不包含。

进入 **准备文库**，点击 **读取 / 更新文献**。完成后即可进入 **找文献**，使用全局搜索。此步骤不需要 API Key。

### 2. 连接 AI（使用研究关键词时需要）

进入 **设置 → API 设置**，填写服务商提供的配置：

| 配置项   | 填写内容                                                    |
| -------- | ----------------------------------------------------------- |
| Base URL | API 服务地址；使用 DeepSeek 时为 `https://api.deepseek.com` |
| 模型     | 你所用服务支持的模型名称                                    |
| API Key  | 在服务商平台创建的 API 密钥                                 |

插件默认配置为 DeepSeek，也支持自定义兼容 OpenAI 格式的服务。点击 **保存 API**，再点击 **测试连接**。

保存后，配置会锁定，密钥显示为圆点。需要更改时点击 **修改 API**；编辑时密钥留空会保留原密钥。

### 3. 生成研究关键词

回到 **准备文库**，点击 **生成研究关键词**。插件会为当前范围内的文献生成以下关键词：

| 类别     | 中文示例               | 英文示例                                 |
| -------- | ---------------------- | ---------------------------------------- |
| 研究区域 | 中国、黄土高原         | China, Loess Plateau                     |
| 研究对象 | 植被韧性、森林生态系统 | Vegetation resilience, Forest ecosystems |
| 研究方法 | 遥感、时间序列分析     | Remote sensing, Time series analysis     |

以上仅为示例，实际结果由论文元数据和模型决定。信息不足时，对应类别可能为空。

生成过程中可以停止，已完成的结果会保存；再次点击生成时会继续处理缺失的关键词。在 Zotero 主列表选中一篇论文，展开 **所选论文的研究关键词**，点击 **查看所选论文**，可查看结果并切换中英文。

## 如何搜索

### 全局搜索

在 **找文献 → 全局搜索** 输入内容，点击 **搜索文献**，或在输入框中按回车。

搜索范围包括已读取的条目信息和已生成的中英关键词，不区分英文字母大小写。多个词用空格分隔，表示需要同时匹配，例如 `China vegetation`。

### 条件搜索

点击 **添加条件**，选择字段、判断方式和值。默认没有条件；**移除此条件** 会删除最后添加的一条，没有条件时按钮置灰。

例如，查找关于中国植被的期刊文章，可以添加：

| 字段     | 判断      | 值       |
| -------- | --------- | -------- |
| 条目类型 | 包含 / 是 | 期刊文章 |
| 研究区域 | 包含 / 是 | 中国     |
| 研究对象 | 包含 / 是 | 植被     |

两条及以上条件会显示 **条件关系**：

- **全部满足**：文献必须符合所有条件。
- **任一满足**：符合其中一条条件即可。

如果同时填写全局搜索内容，结果还必须匹配全局搜索。空白条件会被忽略；尚未生成关键词的文献不会匹配对应的“包含”条件，但会匹配“不包含”条件。

结果直接显示在 **Zotero 主列表**。点击左侧其他分类即可退出搜索结果。搜索时会清空 Zotero 原生快速搜索框和标签筛选，避免它们进一步限制结果。

顶部选择的文库或分类范围对读取、关键词生成和搜索共用。搜索只使用已读取的文献，新增文献后请先更新。

## 更新与标签设置

在 **设置 → 索引与标签** 中可以选择：

| 选项                   | 作用                                                 |
| ---------------------- | ---------------------------------------------------- |
| 手动更新               | 需要时点击“读取 / 更新文献”                          |
| 自动更新整个个人文库   | 文库发生变化时自动更新条目信息，不自动调用 AI        |
| 仅插件                 | 研究关键词只保存在文献透镜中                         |
| 插件 + Zotero 双语标签 | 同时写入中文和英文原生标签，方便使用 Zotero 标签筛选 |

更改标签保存方式后，点击 **保存标签选项**。原生标签格式如 `研究区域：中国`、`Study region: China`，不带插件名前缀。切回仅插件时，只移除插件记录为自己添加的标签，保留人工已有标签。

条目信息更新后，相关研究关键词需要重新生成。日常更新使用“准备文库”中的两个按钮即可；“维护工具”中的“重新生成全部关键词”会再次调用 API。

## 标题旁的状态灯

| 状态          | 含义                                         |
| ------------- | -------------------------------------------- |
| 红色 · 未连接 | 尚未保存 API 配置；读取文献后仍可搜索元数据  |
| 黄色 · 待生成 | 尚未读取文献，或已读取文献中仍有关键词未生成 |
| 绿色 · 已就绪 | 已读取的文献均已完成关键词准备               |
| 黄色 · 待修复 | 本地索引读取异常，需要检查或重建缓存         |

点击状态灯可前往相应页面。状态灯依据已保存的配置和本地数据判断，不代表实时 API 连通性；验证连接请使用“测试连接”。完成首次准备后，绿色引导文字不再显示。

## 数据与费用

文献元数据和研究关键词保存在本地。普通检索不发送 API 请求；生成关键词时，会将所选文献的元数据（包括摘要、作者和已有标签等）发送到你配置的 API 服务，不发送 PDF 全文。调用费用按服务商规则计算。

AI 关键词用于辅助检索，可能遗漏或误判；结果取决于条目信息的完整程度和模型能力。

## 常见问题

**没有 API Key，能用吗？**  
可以。先读取文献，即可搜索已有元数据；生成三类研究关键词才需要 AI 服务。

**为什么新导入的论文搜不到？**  
确认顶部搜索范围，然后点击“读取 / 更新文献”。使用研究关键词条件时，还需要为新文献生成关键词。

**关键词生成失败怎么办？**  
到 API 设置中测试连接，检查地址、模型名称、密钥和服务商余额。修复后再次点击“生成研究关键词”，会继续处理未完成部分。

**怎样安装后续版本？**  
从 Releases 下载新版 `.xpi`，再次通过“从文件安装插件”安装。当前版本尚未启用自动更新。

**卸载插件会删除论文吗？**  
不会。插件不删除论文。已经写入的原生标签不会因为卸载而自动清除；如需移除，请先切回“仅插件”并保存标签选项。请勿提前手动删除插件缓存，以免丢失标签归属记录。
