# 文献透镜 · Paper Lens

让 Zotero 文库更容易查找。文献透镜读取文献的标题、摘要、作者、标签等条目信息，通过 AI 提取六类中英双语研究关键词和主要结论，帮助你按主题、区域、对象、方法、数据和变量找到相关论文。

[下载安装包](https://github.com/XYFQS/paper-lens/releases) · [反馈问题](https://github.com/XYFQS/paper-lens/issues) · [更新记录](CHANGELOG.md)

## 能做什么

- **搜索文献信息**：在本地搜索标题、摘要、作者、结论及其他已读取的条目信息，无需调用 AI。
- **生成研究画像**：为每篇文献提取主题、区域、对象、方法、数据、变量六类关键词，每类最多 5 个，中文和英文成对生成；同时提取最多 3 条主要结论。
- **文献身份证**：在搜索页以信息卡片的形式查看当前选中论文的记忆句、研究画像、结论和文献管理字段，点击 **编辑** 即可修改。
- **记忆句**：自动生成 `作者 年份 | 期刊 | 区域 | 方法 | 结论` 形式的一句话摘要，可以手动改写。
- **人工校正**：停用不准确的 AI 关键词，或补充自己的中英配对；重新生成画像后仍然有效。
- **组合条件检索**：按条目类型、六类关键词、年份、期刊、阅读进度、重要程度和用途筛选，结果直接显示在 Zotero 主列表。
- **选择标签保存方式**：关键词可仅保存在插件中，也可同步为 Zotero 原生英文规范标签。

插件不读取 PDF 全文，不推测论文结果，不移动文献，不创建或删除文献分类。

## 下载与安装

当前版本为 **2.0.1**，已在 **Windows、Zotero 9.0.6（64 位）** 上测试。目前支持个人文库，暂不支持群组文库。

1. 打开 [Releases 下载页面](https://github.com/XYFQS/paper-lens/releases)，在所需版本的 **Assets** 中下载以 `.xpi` 结尾的文件。
2. 在 Zotero 中打开 **工具 → 插件**，点击齿轮菜单，选择 **从文件安装插件**。
3. 选择下载的 `.xpi` 文件，按提示完成安装；如提示重启，请重启 Zotero。
4. 点击右侧原生侧栏中的文献透镜图标，即可显示或隐藏插件；也可通过工具菜单打开。

**`.xpi` 就是安装包，不需要解压。** `Source code` 和 `-source.zip` 是源码，普通用户无需下载，也无需安装 Node.js 或其他开发环境。

从 1.x 升级无需任何操作：首次读取文献信息时，插件会自动把旧索引升级为新结构，并在同一目录留下 `index-v1-backup.json` 备份。旧的研究区域、研究对象、研究方法关键词会保留，主题、数据、变量三类为空，并提示重新生成。

## 第一次使用

插件顶部有 **找文献**、**文库**、**设置** 三个页面。先在顶部选择 **整个个人文库** 或一个指定分类，需要同时处理其子分类时勾选 **包含子分类**（默认不包含）。这个范围对读取、生成画像和搜索共用。

### 1. 读取文献信息

进入 **文库**，点击 **读取 / 更新文献**。完成后即可进入 **找文献** 使用搜索。此步骤不需要 API Key。

### 2. 连接 AI（生成研究画像时需要）

进入 **设置 → API 设置**，填写服务商提供的配置：

| 配置项   | 填写内容                                                    |
| -------- | ----------------------------------------------------------- |
| Base URL | API 服务地址；使用 DeepSeek 时为 `https://api.deepseek.com` |
| 模型     | 你所用服务支持的模型名称                                    |
| API Key  | 在服务商平台创建的 API 密钥                                 |

插件默认配置为 DeepSeek，也支持自定义兼容 OpenAI 格式的服务。点击 **保存 API**，再点击 **测试连接**。

保存后，配置会锁定，密钥显示为圆点。需要更改时点击 **修改 API**；编辑时密钥留空会保留原密钥。

### 3. 生成研究画像

回到 **文库**，点击 **生成研究画像**。插件只为尚未生成或文献信息已变化的条目调用 AI，可中断后继续。提取结果如下：

| 类别 | 含义           | 英文示例                                 |
| ---- | -------------- | ---------------------------------------- |
| 主题 | 科学问题       | Vegetation resilience, Drought legacy    |
| 区域 | 实际研究区     | China, Loess Plateau, Global             |
| 对象 | 研究对象或系统 | Vegetation, Forest, Soil                 |
| 方法 | 实际使用的方法 | Random Forest, SHAP, Theil-Sen estimator |
| 数据 | 实际使用的数据 | MODIS, ERA5, CHIRPS                      |
| 变量 | 实际测量的变量 | NDVI, GPP, VPD, Soil moisture            |

每类最多 5 个，中文和英文成对出现。**信息不足时对应类别为空，插件不会为了凑数而猜测。** 研究区域只依据论文本身，不会根据作者单位、出版社地址或语言推断。主要结论同样只来自标题、摘要或明确的元数据，最多 3 条。

## 文献身份证

在 **找文献** 页面，插件显示当前选中论文的文献身份证：在主列表点选一篇论文，或打开它的阅读器即可。

默认是**信息卡片**：只有文字，没有输入框、没有删除按钮，也没有维护动作。需要修改时点击右上角的 **编辑**，控件才会出现；改完点击 **完成** 收起。切换到另一篇论文会自动回到卡片状态。

| 区块     | 内容                                                            |
| -------- | --------------------------------------------------------------- |
| 记忆句   | `作者 年份 \| 期刊 \| 区域 \| 方法 \| 结论`，缺少的字段自动省略 |
| 研究画像 | 六类中英关键词                                                  |
| 主要结论 | AI 提取的最多 3 条结论                                          |
| 文献管理 | 阅读状态、重要程度、在论文中的用途                              |

信息顺序固定为：论文基本信息 → 记忆句 → 研究画像 → 主要结论 → 文献管理。标题下方是一行 `作者 · 年份 · 期刊`，只有阅读状态或重要程度不是默认值时，才额外显示小徽标。缺失的字段一律显示为 `—`，不会留下空行。

**阅读状态、重要程度和论文用途完全由你设置，AI 不会判断哪篇是核心文献、适合 Discussion 还是属于 Introduction。**

编辑状态下可以改写记忆句，输入框的占位提示就是当前自动生成的版本；点击 **完成** 生效，点击 **恢复自动生成** 清除改写，重新使用自动版本。生成和修改记忆句都不会额外调用 AI。

关键词以标签形式排列，**一个标签同时包含中文和英文**。编辑状态下每个标签右侧出现 **×**，点击即停用该词，AI 下次重新生成时也不会再出现。六个类别共用同一套添加控件：先选类别，再填写中英文后点击 **添加**，中英文必须同时填写。做过人工改动后才会出现 **恢复 AI 原始画像**，一次清除全部改动，回到 AI 的原始结果。人工校正不会修改 AI 的原始分析，只是叠加在其上。

阅读状态和重要程度在编辑状态下用下拉框设置，论文用途用可反复点按的标签切换。

## 如何搜索

### 全局搜索

在 **找文献 → 全局搜索** 输入内容，点击 **搜索文献**，或在输入框中按回车。

搜索范围包括已读取的条目信息、已生成的中英关键词、主要结论和记忆句，不区分英文字母大小写。多个词用空格分隔，表示需要同时匹配，例如 `中国 遥感`。

### 条件搜索

点击 **添加条件**，选择字段、判断方式和值。默认没有条件；**移除此条件** 会删除最后添加的一条，没有条件时按钮置灰。

可用的字段有十二个：条目类型、主题、区域、对象、方法、数据、变量、年份、期刊、阅读进度、重要程度、用途。例如，查找关于中国植被的期刊文章：

| 字段     | 判断      | 值       |
| -------- | --------- | -------- |
| 条目类型 | 包含 / 是 | 期刊文章 |
| 区域     | 包含 / 是 | 中国     |
| 对象     | 包含 / 是 | 植被     |

几条关键词条件可以组合，例如“区域 = 中国”且“方法不包含 = XGBoost”。两条及以上条件会显示 **条件关系**：

- **全部满足**：文献必须符合所有条件。
- **任一满足**：符合其中一条条件即可。

如果同时填写全局搜索内容，结果还必须匹配全局搜索。空白条件会被忽略；尚未生成画像的文献不会匹配对应的“包含”条件，但会匹配“不包含”条件。

结果直接显示在 **Zotero 主列表**。点击左侧其他分类即可退出搜索结果。搜索时会清空 Zotero 原生快速搜索框和标签筛选，避免它们进一步限制结果。

## 更新与标签设置

在 **设置 → 索引与标签** 中可以选择：

| 选项                   | 作用                                               |
| ---------------------- | -------------------------------------------------- |
| 手动更新               | 需要时点击“读取 / 更新文献”                        |
| 自动更新整个个人文库   | 文库发生变化时自动更新条目信息，不自动调用 AI      |
| 仅插件                 | 关键词只保存在文献透镜中                           |
| 插件 + Zotero 原生标签 | 同时写入英文规范原生标签，方便使用 Zotero 标签筛选 |

更改标签保存方式后，点击 **保存标签选项**。原生标签使用英文规范前缀，便于跨库统一筛选：

| 前缀  | 类别 | 示例                       |
| ----- | ---- | -------------------------- |
| `T::` | 主题 | `T::Vegetation resilience` |
| `R::` | 区域 | `R::China`                 |
| `O::` | 对象 | `O::Vegetation`            |
| `M::` | 方法 | `M::Remote sensing`        |
| `D::` | 数据 | `D::MODIS`                 |
| `V::` | 变量 | `V::NDVI`                  |

标签写入为 Zotero 的**自动标签**，只保留一套英文命名，不会同时写中文。切换关键词或切回“仅插件”时，插件只会删除自己记录在案的标签；**人工创建的同名标签不会被删除，也不会被插件占用**。

条目信息更新后，相关研究关键词需要重新生成。日常更新使用“文库”页面中的两个按钮即可；“维护工具”中的“重新生成全部画像”会再次调用 API。

## 标题旁的状态灯

| 状态          | 含义                                        |
| ------------- | ------------------------------------------- |
| 红色 · 未连接 | 尚未保存 API 配置；读取文献后仍可搜索元数据 |
| 黄色 · 待生成 | 尚未读取文献，或已读取文献中仍有画像未生成  |
| 黄色 · 待更新 | 有些文献的条目信息已变化，建议重新生成画像  |
| 绿色 · 已就绪 | 已读取的文献均已完成画像                    |
| 黄色 · 待修复 | 本地索引读取异常，需要检查或重建缓存        |

点击状态灯可前往相应页面。状态灯依据已保存的配置和本地数据判断，不代表实时 API 连通性；验证连接请使用“测试连接”。完成首次准备后，绿色引导文字不再显示。

## 数据与费用

文献元数据、研究关键词、人工校正和文献身份证字段都保存在本地。普通检索不发送 API 请求；生成画像时，只发送所选文献的题录字段（标题、摘要、作者、期刊、年份、已有标签等），**不发送 PDF、附件、笔记内容或本地路径**。调用费用按服务商规则计算。

AI 提取的关键词和结论用于辅助检索，可能遗漏或误判；结果取决于条目信息的完整程度和模型能力。

## 常见问题

**没有 API Key，能用吗？**  
可以。先读取文献，即可搜索已有元数据、填写阅读进度等字段；生成六类关键词和结论才需要 AI 服务。

**为什么新导入的论文搜不到？**  
确认顶部搜索范围，然后点击“读取 / 更新文献”。使用关键词条件时，还需要为新文献生成画像。

**生成失败怎么办？**  
到 API 设置中测试连接，检查地址、模型名称、密钥和服务商余额。修复后再次点击“生成研究画像”，会继续处理未完成部分。

**AI 提取的关键词不对怎么办？**  
在文献身份证中点击 **编辑** 后停用它，或补充正确的关键词。停用后 AI 重新生成也不会再出现；也可以点 **恢复 AI 原始画像** 回到 AI 的原始结果。

**从 1.x 升级会丢失数据吗？**  
不会。旧索引会自动升级并备份为 `index-v1-backup.json`，原有文献信息和关键词都会保留。升级后建议重新生成一次画像，补齐四类新关键词。

**怎样安装后续版本？**  
从 Releases 下载新版 `.xpi`，再次通过“从文件安装插件”安装。当前版本尚未启用自动更新。

**卸载插件会删除论文吗？**  
不会。插件不删除论文。已经写入的原生标签不会因为卸载而自动清除；如需移除，请先切回“仅插件”并保存标签选项。请勿提前手动删除插件缓存，以免丢失标签归属记录。
