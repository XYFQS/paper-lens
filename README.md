# 文献透镜 · Paper Lens

Windows / Zotero 9.0.6 独立插件。缓存论文条目的全部书目元数据，生成中英双语研究区域、研究对象、研究方法关键词，并通过本地条件搜索在 Zotero 主列表显示结果。不读取 PDF 全文，不保存 AI 文字总结。

## 安装和使用

工具 → 插件 → 齿轮 → 从文件安装，选择 `dist/paper-lens-1.0.0.xpi`。点击原生侧栏导航中“定位”按钮下方的文献透镜图标，可显示或隐藏插件；文库与阅读器均提供入口，工具菜单仍可开关。与旧 AI Organizer 使用不同 ID，不依赖旧代码或数据。

1. 在顶部选择整个个人文库或指定分类，可勾选包含子分类（默认关闭）。范围在各页面之间共用。
2. 首次进入“准备文库”，点击“读取 / 更新文献”。这一步无需 API；完成后即可到“找文献”搜索标题、摘要和其他元数据。
3. 想按研究区域、对象或方法筛选时，到“设置”填写 API 的 Base URL、模型和密钥，保存并测试连接。保存后配置锁定，需点击“修改 API”才能编辑；密钥留空会保留原值。
4. 回到“准备文库”，点击“生成研究关键词”。每篇每类 0–5 个关键词，同一次请求生成中英对应版本。元数据不足时留空；每批完成即保存，失败或停止后可继续。到“找文献”下方展开“所选论文的研究关键词”查看结果，并切换显示语言。
5. 在“找文献”的全局搜索框输入内容，必要时在“条件搜索”下点击“添加条件”。默认没有条件行，“移除此条件”删除最后添加的一条，空状态下置灰；两条及以上才显示“全部满足 / 任一满足”。普通框对全部缓存元数据和 AI 关键词进行不区分大小写的包含搜索，空格分词之间为 AND。条件可选原生条目类型和三类研究关键词，支持包含、不包含以及全部/任一条件。普通框始终与条件组为 AND。空条件忽略，未生成关键词的条目“包含”不匹配、“不包含”匹配。
6. 搜索通过临时搜索视图直接在 Zotero 主列表显示匹配论文。不会移动条目或创建文献分类。点击左侧其他分类即可退出结果视图；文库变化后请在插件中重新搜索。原生快速搜索框和标签筛选会清空，以保证完整显示结果。

## 缓存与标签

缓存文件位于 Zotero 数据目录的 `paper-lens/index.json`，临时文件原子写入避免中途写坏。缓存所有书目字段、作者、现有标签、集合归属和关联信息、条目 key 和修改时间；不读取独立笔记内容或附件文件路径。索引面向常规书目条目，独立笔记/附件不是论文，不纳入条件检索。群组文库暂不支持。

手动模式只在点击更新或 AI 分析前刷新；自动模式监听本地文库变化，合并变更后更新整个个人文库的元数据，不自动调用 AI。元数据变化会将对应 AI 关键词标为缺失，避免旧标签用于搜索。手动模式中的结果反映上次索引快照；需要最新元数据时先更新。搜索按实时分类成员限定范围，只使用已索引条目，并提示未索引数量。

“仅保存在文献透镜中”不写原生标签；同步原生标签会同时写入中英两套，格式例如 `研究区域：中国` 和 `Study region: China`，不添加插件名前缀。到“设置 → 索引与标签”更改选项，并点击“保存标签选项”。原生标签模式下，插件启动或再次同步时会迁移插件自己添加的旧前缀标签；不会移除人工添加的同名或相似标签。切回仅插件只移除插件拥有的标签。清理以缓存中的归属记录为依据；请勿手工删除缓存后再要求自动清理旧标签。

首次读取文献并完成已收录文献的研究关键词生成后，绿色引导框会永久收起，重启后也不再出现。标题右侧用状态灯显示：红色“未连接”表示未保存 API 配置；黄色“待生成”表示尚未读取文献或还有关键词未生成；绿色“已就绪”表示本地已收录文献已准备好。索引损坏时显示黄色“待修复”。点击状态灯可进入对应页面。状态依据已保存的配置和本地索引，不在后台持续探测 API 网络连接。

每次 AI 请求发送所选论文的书目元数据，包括作者、摘要、现有标签等。无额外中转服务；远程地址需 HTTPS，本机服务可 HTTP。API 服务需支持 `max_tokens` 和非流式 JSON 文本输出。语义标签准确性取决于模型和元数据。

默认地址 `https://api.deepseek.com`、模型 `deepseek-v4-flash`，对应 [DeepSeek 官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/)（2026-09-09 核对）。可以修改地址和模型接入其他兼容服务。

## 开发与开源

修改源码时无需反复安装 XPI。在项目目录执行以下命令，可打开独立开发预览窗口；保存 `addon/` 文件后约 2 秒自动刷新。也可通过 VS Code 的“运行任务 → 文献透镜：开发预览（自动刷新）”启动。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/dev.ps1
```

开发窗口使用独立演示文库，不读取正式文库。完整说明见 [开发预览](docs/DEVELOPMENT.md)。

测试和打包需要 Node.js 20+ 与 Windows PowerShell/.NET，无运行时 npm 或 Python 依赖。开发格式化使用 Prettier，运行 `npm install` 后可执行 `npm run format` 和 `npm run format:check`。模块说明见 [源码结构](docs/ARCHITECTURE.md)。

```powershell
node --test tests/*.test.cjs
./scripts/build.ps1
```

`dist` 包含 XPI、独立完整源码包及 SHA256SUMS。MIT 许可。GitHub 发布前设置作者及实际更新 URL；当前 `example.invalid` 是满足 Zotero 9 强制字段的占位地址，不提供自动更新。测试记录见 `docs/VALIDATION.md`。

旧项目清理受到本机自动审批拦截，因此旧项目目录暂留在此项目上级目录；它们不会被打入任何新安装包。请在 Zotero 的插件管理中卸载旧的“AI 文献整理 · AI Organizer”，避免两套侧栏同时显示。原生文献分类不是插件私有数据，本插件不删除它们。
